Como ler o ciclo

1. Quintas ascendentes
C → G → D → A → E → B → F♯. Cada passo acrescenta um sustenido.
2. Movimento anti-horário
C → F → B♭ → E♭ → A♭. Cada passo acrescenta um bemol.
3. Relativas menores
A relativa menor fica três semitons abaixo da maior e compartilha sua armadura: C maior ↔ A menor.
4. Campo harmônico maior
I maior, ii menor, iii menor, IV maior, V maior, vi menor e vii° diminuto.
5. Treino sugerido
Escolha uma tonalidade, diga os sete acordes em voz alta e avance uma posição na roda. Observe o que mudou.
